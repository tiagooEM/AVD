# Prompts

Esta pasta serve para três propósitos:

1. **Rascunho do layout**: salve os wireframes em [`entregas/`](../entregas/) como `rascunho-dashboard1.png` e `rascunho-dashboard2.png` (ou `.jpg`). Mostre onde ficam a sidebar, os filtros e cada bloco de conteúdo. Se um wireframe for feito depois do código, identifique-o como documentação retrospectiva; não o apresente como evidência de planejamento prévio.
2. **Template de prompt do rascunho → esqueleto**: [layout-skeleton-prompt.md](layout-skeleton-prompt.md) traz o template de 4 blocos (Contexto, Entrada, Restrições, Formato de saída). Preencha com o caminho do seu rascunho, anexe a imagem e envie à ferramenta de IA.
3. **Declaração de Uso de IA**: [declaracao-uso-ia.md](declaracao-uso-ia.md) registra os prompts e o uso de IA. Revise o formulário oficial em [`entregas/DECLARACAO_IA.pdf`](../entregas/DECLARACAO_IA.pdf), assine e entregue no repositório e no Classroom.

Dica: guarde aqui uma cópia dos prompts que você realmente usou, para preencher a declaração de uso de IA de forma mais simples.

Os rascunhos fazem parte do entregável: não os coloque no `.gitignore`.
